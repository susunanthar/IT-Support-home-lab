**#** **IT-Support-home-lab**



Hands-on IT support home lab projects covering Windows Server, Active Directory, file permissions, troubleshooting, and Microsoft 365.





**##** **Projects**



**### Project 01 - Windows Server File Share Access Control**



Configured Active Directory security groups and NTFS permissions to control access to a Windows Server shared folder.



**### Project 02 - Active Directory User \& Account Management**



Configured Active Directory user accounts and account policies, and demonstrated user account management and group membership verification.



**### Project 03 - Windows Network Troubleshooting**



Practiced Windows network troubleshooting using 'ipconfig', 'ping', 'nslookup', and 'tracert'. Simulated a network adapter failure and incorrect DNS configuration, diagnosed connectivity and name-resolution issues, and verified recovery after restoring the original settings.



**### Project 04 - Windows OS and Performance Troubleshooting**



Practiced Windows OS troubleshooting using built-in diagnostic tools in a virtual lab environment. Investigated system resource usage, reviewed startup applications, checked windows update status and system reliability, and used System File Checker (SFC) to repair corrupted system files.



**### Project 05 - Remote Desktop and Connectivity Troubleshooting**



Practiced Remote Desktop Protocol (RDP) connectivity troubleshooting between Windows client and server virtual machines. Verified the server hostname and IP address, checked Remote Desktop configuration and Windows Firewall rules, tested network reachability with 'ping', and used PowerShelll to investigate TCP connectivity on port 3389. Successfully established a remote desktop session and practiced distinguishing ICMP reachability from TCP port availability.
